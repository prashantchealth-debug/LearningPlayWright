# Learning Playwright with JavaScript

A comprehensive learning project for mastering Playwright automation testing framework with JavaScript.

## 📋 Project Overview

This repository contains practical examples and exercises for learning Playwright, a modern web automation library that supports testing across Chrome, Firefox, and WebKit browsers.

## 🚀 Getting Started

### Prerequisites

- **Node.js** (v14 or higher)
- **npm** or **yarn**

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/prashantchealth-debug/LearningPlayWright.git
   cd LearningPlayWright
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Install Playwright browsers:
   ```bash
   npx playwright install
   ```
